# The Economist Fetcher

自动抓取《经济学人》周刊并生成 EPUB 文件。

## 功能

- 每周五自动抓取最新一期《经济学人》
- 生成 EPUB 格式
- 支持手动触发指定日期

## 使用方法

### 自动运行
每周五 UTC 0:00（北京时间周五早上 8:00）自动运行。

### 手动触发
1. 进入仓库 → **Actions**
2. 选择 **Fetch The Economist**
3. 点击 **Run workflow**
4. 输入日期（可选，格式：YYYY-MM-DD）
5. 点击 **Run workflow**

## 下载结果

运行完成后，在 **Artifacts** 区域下载 EPUB 文件。
